# Historical HESPN-v4 material

This directory preserves older HESPN development scripts, diagnostics, logs, and broader exploratory cryptanalysis for provenance.

These files are **not** the current reference implementation and are **not** part of the evidentiary chain for the Cryptologia construction manuscript.

- `analysis/` contains earlier revision-support code.
- `diagnostics/` contains older HESPN-v4 differential, linear, NIST, confirmation, and keystream scripts/logs formerly stored at repository root.
- `broader_cryptanalysis/` contains older boomerang/calibration and high-volume experimental outputs that are outside the current construction paper.

The current implementation is `../hespn_reference.py`.

Matched orientation-scheduling and cross-byte boundary work associated with the separate manuscript **Structural Limits of Orientation Scheduling in Byte-Local GF(2) Diffusion Layers** is maintained in its dedicated repository rather than duplicated here:

<https://github.com/ja9925ydbsu/structural-limits-orientation-scheduling>
